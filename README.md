# 📲 WhatsApp Bulk Messenger (PyWhatKit)

Envía mensajes de WhatsApp a **múltiples contactos** desde tu PC usando WhatsApp Web y PyWhatKit.  
Configuración por **variables de entorno** y **espera entre envíos** para evitar bloqueos.

> Requisitos: tener **sesión iniciada en WhatsApp Web** en el navegador que abre PyWhatKit.

---

## 🚀 Setup

```bash
pip install -r requirements.txt
cp .env.example .env
# edita .env y coloca tus números/mensaje
